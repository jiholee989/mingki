# Agent 작업 기준

- 작업 범위: `agent/`. 외부 계약은 `docs/BACKEND_API.md`를 참고한다.
- 흐름: 요건 → 상품 영향 → 제안 → 검증 → 검토 → 보고. 백엔드 승인에는 apply를 거친다.
- LLM은 근거 기반 제안을 작성한다. 코드가 값·단위·출처를 검증하고 실패 항목만 보완한다.
- CLI는 부분 승인·제외·재작성·직접 수정과 버전 관리를 지원한다.
- 실제 반영은 승인 ID·승인 목록을 검증한 뒤 MCP로 요청하고 큐 작업 완료를 확인한다.
- API 키는 `.env`에 보관하며 출력·커밋하지 않는다.
- 자동 테스트는 실제 API와 DB 쓰기를 사용하지 않는다. 실행 명령: `uv run pytest -q`.
- 커밋은 매번 사용자의 명시적인 허락을 받은 뒤 수행한다. 푸시는 명시적인 요청이 있을 때 수행한다.
