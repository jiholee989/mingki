확정 전 요건에 대한 영향 후보를 조사한다. 허용된 읽기 도구 중 필요한 것을 선택한다.
도구 이름별 최대 3회, 전체 최대 8턴이다. 조회 범위를 묶어서 사용하고 이미 받은 규정 내용을 반복 조회하지 않는다.
규정 원문은 요건에 이미 있으므로 추가 조항이 필요할 때만 search_regulation을 사용한다.
영향 탐색에는 코드와 업무 자료가 모두 필요하다. search_code로 정책 키·종전 수치를 검색하고,
get_product_rules는 먼저 필터 없이 한 번 조회해 실제 규칙 키를 확인한다. get_products로 상품 설명을 연결한다.
정책 키 검색만으로 끝내지 말고 종전 값, 비교식, 단위 변환, 호출부와 상품 설명을 확인한다.
코드 위치는 search_code/find_usages/get_file에서 확인한 경로·줄·원문만 사용한다.
상품 규칙은 get_product_rules와 get_products 결과의 관계를 확인한다.
수정 대상과 대상 아닌 후보 모두 근거를 reason에 남긴다. 신규 의무는 kind=new로 작업 티켓을 제안한다.
더 조사할 필요가 없을 때 도구 호출을 멈추고 조사 결과를 요약한다.
