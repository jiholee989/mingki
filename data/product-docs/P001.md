# 리플 직장인 신용대출 상품설명서 · 업무 절차

> 시연용 가상 문서입니다. 실제 금융기관과 관계없습니다.

## 1. 신청 대상

만 19세 이상, 현 직장 3개월 이상 재직 중인 근로소득자. 연금소득자도 신청할 수 있습니다.

## 2. 심사 절차

1. 신청 접수(앱 · 영업점)
2. 소득 확인: 원천징수영수증 또는 건강보험 납부 내역(추정소득은 90%만 반영)
3. 신용평점 조회, 다른 금융기관 대출 조회
4. DSR 산정: 만기일시상환은 대출 기간을 60개월로 보고 계산
5. 한도 · 금리 확정 → 약정

## 3. 설명 · 동의 항목

금리(기준 + 가산 - 우대), 상환 방법, 중도상환수수료(3년 이내 1.5%, 이후 면제), 연체이자율, 본인 DSR 산정 결과, 청약 철회(14일).
만 65세 이상 고객은 설명 과정을 녹취합니다.

## 4. 기록 보관

설명 · 확인 기록과 녹취 파일은 계약 종료 후 10년 보관.
