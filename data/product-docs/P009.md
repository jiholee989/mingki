# 리플 사장님 신용대출 상품설명서 · 업무 절차

> 시연용 가상 문서입니다. 실제 금융기관과 관계없습니다.

## 1. 신청 대상

사업자등록 후 12개월 이상 지난 개인사업자. 사업자금 용도만 가능.

## 2. 심사 절차

1. 사업자등록 · 부가세 신고 확인
2. 사업소득 대비 상환능력(DSCR 1.25 이상) 확인
3. 가계대출이 아니므로 DSR 한도는 적용하지 않음

## 3. 설명 · 동의 항목

금리, 상환 방법, 자금 용도 외 사용 시 회수 가능성.

## 4. 기록 보관

설명 기록 10년.
