# 상품설명서 · 업무 절차 (가상)

상품마다 신청 대상, 심사 절차, 설명 · 동의 항목, 기록 보관, 화면 · 설명서 안내 문구를 적은 문서입니다. 숫자 규칙(`data/business/product_rules.json`)으로 표현되지 않는 변경(설명 의무 신설, 안내 문구 수정 등)을 판단할 때 씁니다.

| 파일 | 형식 |
|---|---|
| `{product_id}.md` | frontmatter(`product_id`, `name`, `updated_at`, `fictional`) + `## 번호. 섹션` |

실제 문서처럼 정리되지 않은 부분이 있습니다. 작성일이 오래된 문서, 비어 있는 섹션("작성 중"), 규칙과 표현이 다른 숫자(예: "40퍼센트")가 있습니다. 문서에 없는 절차는 Agent가 지어내지 않고 "추가 확인 필요"로 답해야 합니다.

이 폴더도 Agent 입력이므로 판단 근거나 정답은 넣지 않습니다. 어느 MCP가 이 문서를 제공할지(Vector DB 색인 포함)는 아직 정하지 않았습니다.
