# 리플 직장인 마이너스통장 상품설명서 · 업무 절차

> 시연용 가상 문서입니다. 실제 금융기관과 관계없습니다.

## 1. 신청 대상

현 직장 1년 이상 재직 중인 근로소득자.

## 2. 심사 절차

1. 소득 확인
2. DSR 산정: 실제 사용 금액이 아니라 약정 한도 전액, 기간 60개월 기준
3. 1년 약정, 최대 4회 갱신. 갱신 때 한도를 늘리지 않으면 DSR 한도 확인을 생략할 수 있음

## 3. 설명 · 동의 항목

금리, 한도 약정 방식, 갱신 조건, 청약 철회(15일, 법정 기준보다 하루 더).

## 4. 기록 보관

설명 기록 10년.
