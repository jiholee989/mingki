# 리플 시니어 든든대출 상품설명서 · 업무 절차

> 시연용 가상 문서입니다. 실제 금융기관과 관계없습니다.

## 1. 신청 대상

신청일 현재 만 65세 이상인 고객. 연금소득만 있어도 신청할 수 있습니다.

## 2. 심사 절차

1. 고령자 전담 창구 상담
2. 연금 수령 내역으로 소득 확인
3. DSR 산정
4. 만 80세 이상이면 지정 조력자에게 신청 사실 안내
5. 약정 → 2영업일 안에 계약 내용 재확인 안내

## 3. 설명 · 동의 항목

쉬운 말 설명서(큰 글씨)로 금리, 상환 방법, 연체 시 불이익을 설명합니다. 설명 과정은 전부 녹취합니다.
3천만원 이상 지급 시 1시간 이체 지연이 있을 수 있음을 안내합니다.

## 4. 기록 보관

녹취 파일 10년 보관.

## 5. 화면 · 설명서 안내 문구

"만 65세 이상이면 누구나 상담받을 수 있습니다."
"최대 3천만원, 중도상환수수료 없음"

## 6. 변경 이력
